# Проверка комплекта 1.3.0

Дата сборки: 20 августа 2026.

- Главный домен `edinburo.ru` переведён на пользовательский Flutter Web.
- Админка вынесена на `admin.edinburo.ru`.
- Flutter Web собирается отдельным production Docker-образом.
- Все 67 Flutter-экранов подключены к backend; служебные административные
  переходы скрыты в публичной web-сборке.
- Nginx выбирает web/admin по `Host` и динамически разрешает адреса контейнеров.
- CI дополнительно собирает Flutter Web и проверяет полный Docker stack.
- Deploy считается успешным только после внешней проверки пользовательского
  сайта, админки и API.

## Предыдущая сборка 1.2.0

Дата сборки: 6 августа 2026.

- Backend validator: 47 Python-файлов, 28 таблиц, 108 API-маршрутов.
- Веб-админка: TypeScript без ошибок.
- Next.js production build: успешно.
- Контрактные тесты админки: 3 из 3.
- В комплект добавлен запускаемый post-install smoke test: SMS-код, вход,
  HttpOnly-сессия, запрос к административному dashboard API и выход.
- Исправлено создание находки из админки: создаётся допустимый черновик,
  который можно дополнить фотографией перед публикацией.
- Docker Compose: YAML корректен, 9 сервисов.
- Установочные shell-скрипты: синтаксис корректен.
- Next.js обновлён до 16.3.0 для устранения уязвимостей высокой критичности.
- Python-зависимости `cryptography` и `pytest` обновлены до исправленных веток.
- Добавлена CI-проверка backend, админки, Flutter и актуальности OpenAPI.
- Устранены замечания Ruff, ESLint и Bandit.
- Зафиксировано ограничение Flutter: API-клиент готов, но UI пока работает на демонстрационных данных.

Полный запуск контейнеров в среде сборки не выполнялся, потому что Docker Engine
в ней отсутствует. Установщик сам ждёт healthcheck всех контейнеров и выполняет
сквозной smoke test на обычном Linux-сервере с Docker Compose 2.20+.
