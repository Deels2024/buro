# Доступ сотрудников

Вход: https://admin.edinburo.ru → телефон → SMS → код приложения-аутентификатора,
если для сотрудника уже включена 2FA. Обычная регистрация в PWA не выдаёт доступ в админку.

| Возможность | Администратор | Модератор |
|---|---|---|
| Проверка и редактирование публикаций | Да | Да |
| Разбор заявлений, споров и совпадений | Да | Да |
| Ответы в поддержку | Да | Да |
| Пользователи, блокировка аккаунтов, роли сотрудников | Да | Нет |
| Организации, интеграции, реклама, настройки | Да | Нет |
| Общая аналитика, журнал аудита, экспорт | Да | Нет |

Ограничения проверяет API. Скрытие разделов в интерфейсе лишь отражает эти права.
При изменении роли сессии сотрудника отзываются; для продолжения нужен новый вход.
Администратор не может снять собственную роль или заблокировать себя.

## Назначение администратора без SSH

1. Владелец номера должен один раз войти в пользовательское приложение и подтвердить SMS.
2. В GitHub → Settings → Environments → production → Environment secrets добавить
   `BN_BOOTSTRAP_ADMIN_PHONE` со значением нужного номера в формате `+7…`.
   Не добавлять номер в исходный код, Variables, workflow inputs или описание PR.
3. В Actions → **Configure production administrator** → Run workflow выбрать `main`.
   Подтвердить запуск для защищённого окружения `production`, если GitHub запросит review.
4. После успешного запуска войти в админку по SMS. Старую пользовательскую сессию
   назначение завершает. Затем секрет можно удалить: роль уже хранится в базе.

Назначение разрешено только workflow владельца репозитория из `main` и защищённого
окружения `production`, с отдельной аудиторией OIDC и одноразовым токеном.
Оно не снимает блокировку аккаунта, не отключает 2FA и не меняет других администраторов.
Повторный запуск для уже назначенного администратора не завершает его сессии.
Номер и его публично перебираемый хеш не попадают в ответ или журнал аудита.

## Модераторы

Сотрудник сначала регистрируется в PWA. Администратор открывает **Пользователи**,
находит его подтверждённый аккаунт и нажимает **Назначить модератором**.
**Снять роль модератора** возвращает обычный пользовательский доступ.
Администратор видит роль, статус и состояние 2FA в карточке пользователя.
