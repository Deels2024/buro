# Production checklist

- [ ] Секреты сгенерированы заново и хранятся вне образа.
- [ ] База, Redis, S3 и резервные копии размещены в выбранном контуре данных.
- [ ] Bucket приватный; CORS bucket разрешает только мобильную схему/нужные домены.
- [ ] Настроены lifecycle-политики для незавершённых upload и удалённых публикаций.
- [ ] SMS имеет лимиты по номеру, IP, устройству и антибот-проверку.
- [ ] Добавлены антивирус/проверка декодирования медиа и удаление EXIF.
- [ ] OpenCLIP разрешает скачивание только с доверенного S3 host.
- [ ] GPT получает только временную ссылку и не получает телефон/точный адрес.
- [ ] Настроены SLO, метрики latency/error rate, алерты и централизованные логи.
- [ ] Настроены retry и dead-letter queue для фоновых задач.
- [ ] WebSocket вынесен в Redis Pub/Sub/realtime gateway при нескольких репликах.
- [ ] Проведены нагрузочное тестирование, security-аудит и проверка восстановления backup.
- [ ] Подготовлены политика конфиденциальности, согласия, сроки хранения и процедура удаления.
- [ ] Реклама маркируется, имеет ERID и отсутствует в критических сценариях возврата вещи.
- [ ] Добавлены App Store/Google Play privacy manifests и формы удаления аккаунта.
