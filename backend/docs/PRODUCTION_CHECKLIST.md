# Production checklist

Актуальный журнал приёмки: [`docs/PRODUCTION_READINESS.md`](../../docs/PRODUCTION_READINESS.md).
Наличие реализации в Git и доступность прежнего релиза не означают, что новая реализация уже развёрнута.

| Пункт | Подтверждение / оставшееся действие |
| --- | --- |
| Публичный каталог, карточки, sitemap, модерация | Реализованы; есть сквозные HTTP/SQL-тесты. |
| SMSC, атомарный OTP, лимиты номера/IP и общего числа SMS | Реализованы; реальное получение SMS двумя пользователями ещё входит в ручную приёмку. CAPTCHA остаётся отдельным этапом перед масштабированием. |
| Сессии и административная 2FA | Реализованы; проверяются конкурирующие refresh, блокировка аккаунта, повтор использованного OTP и защита настройки 2FA. |
| Приватные фотографии, проверка декодирования и EXIF | Реализованы; работа реального хранилища и его внешняя копия проверяются на VPS. Полный антивирусный контур не заявлен. |
| Фоновые задачи, повторы, очередь ошибок | Реализованы для одного worker с Redis-арендой. Есть проверки очередности, повреждённых сообщений и остановки процесса. |
| Контроль релиза и доступности | Проверяются SHA API/Flutter, worker, HTTP/DNS/TLS, robots/sitemap. После merge запускается регулярная проверка в Actions. Доставку уведомлений владелец проверяет в настройках GitHub. |
| Админка в интернете | Блокер: DNS/TLS `admin.edinburo.ru`; 5 сентября публичный Deploy завершился ошибкой именно на ней. |
| Установка, откат и блокировка операций | Скрипты готовы. На VPS требуется подтвердить, что ограниченная SSH-команда запускает `install.sh`, а не Compose напрямую. |
| Зашифрованные копии и восстановление | Скрипты и проверка тестовой БД в CI готовы. Нужны production-ключ age, копия вне VPS, выбранное окно обслуживания и реальное восстановление. |
| OpenAI и поиск похожих фотографий | Описание фото подключено, фактический успешный запрос требует ручной проверки. Для OpenCLIP нужен запущенный AI-профиль. |
| Масштабирование и нагрузка | Нагрузочные испытания, централизованные latency/5xx-метрики и координация нескольких Next.js/API-процессов ещё не приняты. |
| Реквизиты, поддержка, документы и магазины приложений | Требуются подтверждённые данные оператора, рабочий адрес поддержки, юридическая приёмка и store privacy-формы. |

Для массового запуска нужны закрытые внешние пункты и реальный сценарий: два SMS-входа → публикация с фото → модерация → заявление с доказательством → решение → чат → два подтверждения передачи.
