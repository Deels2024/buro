# Бюро находок — Flutter-приложение

Мобильный клиент единой поисковой сети пропаж и находок. Все 67 согласованных
экранов имеют карту API и используют реальные данные FastAPI backend.

## Подключено

- SMS-вход, административный TOTP-2FA и безопасное обновление токенов;
- Keychain/Android Keystore через `flutter_secure_storage`;
- поиск, фильтры, округлённые координаты, карточки и сохранённое;
- загрузка фотографий в S3/MinIO через presigned URL и SHA-256;
- ИИ-описание и визуальный поиск;
- создание пропажи/находки и центр совпадений;
- заявление владельца, ответы, доказательства, решение и апелляция;
- защищённый HTTP/WebSocket-чат;
- согласие на контакты и двухсторонняя QR-передача;
- уведомления, профиль, активные сессии и поддержка;
- организация: заявка, dashboard, инвентарь, заявления, команда, филиалы,
  импорт, аналитика, API-ключи и вебхуки;
- модератор: очередь контента, риски, споры, организации, антифрод и реклама.

## Запуск

Нужен Flutter stable с Dart 3.10+.

```bash
./tool/bootstrap.sh
flutter run --dart-define=BUREAU_API_URL=https://ваш-домен.ru/v1
```

`tool/bootstrap.sh` создаёт платформенные оболочки Android/iOS/Web и выполняет
`flutter pub get`. Для Android-эмулятора локальный backend доступен по
`http://10.0.2.2/v1`.

Production API должен работать по HTTPS. Web-сборке также нужны CORS-настройки
для API и объектного хранилища.

## Безопасность

- access/refresh tokens не пишутся в preferences и логи;
- одновременные 401 используют один refresh-запрос;
- повторяемые изменения получают `Idempotency-Key`;
- точный адрес не показывается в поиске;
- WebSocket получает одноразовый билет вместо access token в URL;
- реклама отсутствует в доказательствах, чате, контактах и QR-передаче.

На Android отключите backup данных приложения или исключите хранилище ключей,
как указано в документации `flutter_secure_storage`. Для iOS добавьте описания
доступа к фото/камере в `Info.plist`.

## Что требует внешней настройки

- реальный SMS-провайдер;
- FCM/APNs и передача push token в `PUT /users/me/devices`;
- подписи Android/iOS и профили App Store/Google Play;
- разрешения камеры и галереи;
- production URL API и файлов;
- ЕСИА, если нужен вход через Госуслуги.
