# Бюро находок — Flutter UI

Кликабельная Flutter-верстка единой поисковой сети пропаж и находок России.

## Что реализовано

- пользовательское приложение: поиск, карта, публикация, совпадения, доказательства, чат и QR-передача;
- кабинет организации: приемка, инвентарь, заявления, команда, филиалы и аналитика;
- кабинет модератора: публикации, риски, споры, организации, антифрод и реклама;
- каталог всех 67 согласованных экранов;
- светлая дизайн-система Material 3;
- безопасные нативные рекламные места только вне критических сценариев.

## Запуск

Проект не использует сторонние runtime-пакеты. После установки Flutter SDK:

```bash
flutter create --platforms=android,ios,web --org ru.buronahodok .
flutter pub get
flutter run
```

Команда `flutter create` добавит стандартные платформенные оболочки, не меняя содержимое `lib/`.

Либо выполните готовый скрипт:

```bash
./tool/bootstrap.sh
```

## Подключение API

В `lib/data/` уже добавлены `BureauApiClient` и единая конфигурация адреса сервера. Адрес передаётся при запуске:

```bash
flutter run --dart-define=BUREAU_API_URL=https://api.example.ru/v1
```

Клиент синхронизирует обновление access token, один раз повторяет исходный запрос после 401, поддерживает `Idempotency-Key` и возвращает `X-Request-ID` в ошибке. Для хранения `refresh_token` подключите `flutter_secure_storage` в реализации `BureauTokenStore`; небезопасного хранения токенов в обычных preferences в проекте нет.

До задания реального API URL интерфейс открывается на демонстрационных данных, поэтому верстку можно проверять отдельно от сервера. Сопоставление экранов с маршрутами находится в backend-файле `docs/FLUTTER_INTEGRATION.md`.

Структуру и полноту каталога можно проверить даже без Flutter SDK:

```bash
node tool/validate_project.js
```

## Структура

- `lib/features/user` — пользовательские сценарии;
- `lib/features/organization` — кабинет организации;
- `lib/features/admin` — кабинет модерации;
- `lib/features/catalog` — навигация по 67 экранам;
- `lib/core` — тема и переиспользуемые компоненты.

Демо запускается с онбординга. В профиле доступен переход в кабинеты организации, администратора и полный каталог экранов.

## Рекламные места

Нативные рекламные карточки предусмотрены только в ленте и поисковой выдаче. Их нет в доказательствах владения, защищённом чате, раскрытии контактов и QR-передаче вещи — реклама не мешает возврату находки и не маскируется под системные действия.
